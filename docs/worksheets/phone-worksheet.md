# Phone Inspection Worksheet

> The most-wanted items on every resale market. Twelve minutes here saves the price of a screen, a battery, or a heartache. Fill this in with a pen or phone notes.

## Before you leave home

- [ ] Listing screenshot saved (photos + exact wording + price)
- [ ] Sold comps written down: 3 prices + battery % and storage
- [ ] My walk-in offer: $ ____________ - cap: $ ____________
- [ ] Public place + daylight agreed (see [Meetup Safety](../08-meetup-safety.md))
- [ ] Packing: charger + cable, cash, pen; optional: a spare SIM to test cellular

## The ask (by text)

- [ ] Exact model + storage + carrier status confirmed in writing
- [ ] "Why are you selling?" answered
- [ ] Battery % (Maximum Capacity) stated - ________ %
- [ ] "Paid off? Ever reported lost or stolen?" answered honestly on the record

## At the meetup: hardware, device off (2 min)

- [ ] Corners/edges photographed; screen-off scratch hunt at an angle
- [ ] Back glass/casing around the camera lenses checked
- [ ] Charging port: no lint, no wobble in the plug
- [ ] SIM tray intact

## Unlock and identity (2 min)

- [ ] Seller unlocks in my sight
- [ ] About screen: model, storage, carrier status verified - photo taken
- [ ] IMEI read from About screen - photographed
- [ ] Battery Health (Settings > Battery) shown live - not a screenshot: ________ %

## Locks and reset (non-negotiable, from the [locks chapter](../04-locks-and-seed-phrases.md))

- [ ] Seller signs out of Apple ID / removes every Google account - in my sight
- [ ] Samsung account (if any) removed; Find My / Reactivate Lock off
- [ ] Factory reset run in my presence
- [ ] Setup wizard reaches the language screen and **lets me skip every sign-in**
- [ ] No wallet apps remain; no seed-phrase papers ever change hands (see [seed phrases](../04-locks-and-seed-phrases.md))

## Tests (4 min, from [screens](../03-screen-checks.md) + [battery](../02-battery-health.md) + [test drive](../06-test-drives.md))

- [ ] Full brightness reached
- [ ] White test: dead dots? blotches? none noted
- [ ] Black + gray: OLED burn-in ghosts? none noted
- [ ] Touch sweep: both edges, all four corners, diagonal - full coverage, no dead zones
- [ ] Volume buttons, mute switch, power button all click properly (case on and off, if case included)
- [ ] Speakers (earpiece + main): a call plays clean, no crackle at moderate volume
- [ ] Microphone: voice memo recorded and played back clearly
- [ ] Vibration and haptics work
- [ ] Cameras: both lenses for photo, video with audio, flash, zoom levels all steps
- [ ] Wi-Fi joins my hotspot; Bluetooth pairs with my headphones
- [ ] Cellular: my SIM makes a two-second call; data indicator runs
- [ ] Charging: my cable gains ~2% in ten minutes on a wall charger
- [ ] Face ID / Touch ID (if advertised) verifies, or is explained as replacement-era problem

## The close

- [ ] Final agreed price: $ ____________
- [ ] Reset verified at "Hello" screen - **before** money moves
- [ ] Cash counted; two-line receipt written and signed by both
- [ ] IMEI + About photos stored with the receipt

**Red flags found (walk away):** setup wizard asking for the seller's account, "can't show battery health", IMEI with a story, phone still "on a payment plan".

**Walk-away line:** "I'm going to pass today - thanks for showing me it."
