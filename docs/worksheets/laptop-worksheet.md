# Laptop Inspection Worksheet

> Print this page or copy it into phone notes. Fill the lines, trust the marks, and let the worksheet do the remembering so you can do the talking. About 15 minutes, cover to finish.

## Before you leave home

- [ ] Listing screenshot saved (photos + exact wording + price)
- [ ] Sold comps written down: 3 prices + battery claims
- [ ] My walk-in offer: $ ____________ - cap: $ ____________
- [ ] Public place + daylight agreed (see [Meetup Safety](../08-meetup-safety.md))
- [ ] Packing: USB stick ([color test](../assets/color-test.html) + one file), charger, cash, pen

## The ask (by text, before the trip)

- [ ] Exact model + storage confirmed in writing
- [ ] "Why are you selling?" answered plainly
- [ ] Battery % or cycle count stated (any number at all)
- [ ] Owner says they can sign out of everything before the sale - confirmed once

## At the meetup: hardware, device off (3 min)

- [ ] Corners/edges: dents, dings, deep scratches photographed
- [ ] Case halves meet evenly; no gaps lifting near the hinge
- [ ] Hinge opens and holds at any angle; opening lifts nothing on the base
- [ ] Screws show no tool marks (opened-when-unknown = ask what changed)
- [ ] Bottom feet intact; machine sits steady on a flat table
- [ ] Charging port: no lint blockage, no play in the plug
- [ ] Screen-off scratch hunt with a flashlight at an angle

## Unlock and identity (2 min)

- [ ] Seller unlocks it **in my sight**
- [ ] About/system screen: model, storage, RAM verified against listing - photo taken
- [ ] Serial number photographed
- [ ] macOS listed? System Report > Power: cycle count + condition noted - ________
- [ ] Windows listed? `powercfg /batteryreport` run; FULL vs DESIGN capacity noted - ________

## Locks and accounts (non-negotiable, from [locks chapter](../04-locks-and-seed-phrases.md))

- [ ] All accounts visible in Settings/About; seller explains each
- [ ] Apple: sign out of Apple ID happens in my sight (Find My disables)
- [ ] Windows: signed out of Microsoft account; BitLocker status: ____________
- [ ] BIOS/admin passwords: none, or seller removes them now
- [ ] Seller runs the erase to a clean setup screen - all in my presence

## Screen, battery, body (5 min, from [screens](../03-screen-checks.md) + [battery](../02-battery-health.md))

- [ ] Full brightness reached; brightness slider changes actual brightness
- [ ] White test: no dead dots, no blotches, corners not bright over the center
- [ ] Black/dark test: mild corner glow ok, patchy clouds noted: ________
- [ ] Gray steps: no tint shift, no big uniformity problems
- [ ] Keyboard: every key typed in a typing-line test
- [ ] Trackpad: all four corners register + both click corners click
- [ ] Battery holds (macOS: Normal condition / Windows: FULL-vs-DESIGN % noted above)
- [ ] Battery % drop test over our 10 minutes together: ________ to ________

## Systems (5 min)

- [ ] Wi-Fi: joins my hotspot fast and holds five minutes
- [ ] Bluetooth: pairs with my headphones
- [ ] Speakers: both sides play, no crackle at moderate volume
- [ ] Audio out: headphone jack (if present) plays
- [ ] Camera opens and focuses; mic records and plays back
- [ ] USB-A: my stick reads in each port; USB-C charges from each port
- [ ] Sleep/wake: lid closes, opens, back to desktop in seconds, no freeze
- [ ] Fan + heat: two-three minutes of real work; warm ok, too-hot-to-touch noted
- [ ] Reset to clean setup screen (or my clean-install-at-home plan, per [wipe chapter](../09-wipe-it.md))

## The close

- [ ] Final agreed price: $ ____________  (totally fine to thank them and pass)
- [ ] Wipe verified to a clean setup screen - happens before money moves
- [ ] Cash handed over; a simple two-line receipt written and signed by both
- [ ] Serial + IMEI/About photo stored with the receipt

**Red flags found (walk away, no debate):** still-signed-in accounts that can't drop, BIOS password the seller can't remove, visible swelling, "I can't show the battery screen".

**Walk-away lines, if needed:** "Today's just not the day for me at this number - good luck with the sale."
