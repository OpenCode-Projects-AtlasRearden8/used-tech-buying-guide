# Tablet Inspection Worksheet

> A phone that gave up pocket duty is a tablet: fewer radios, bigger screen, same discipline. Ten minutes, cover to finish.

## Before you leave home

- [ ] Listing screenshot saved (photos + exact wording + price)
- [ ] Sold comps written down: 3 prices + storage
- [ ] My walk-in offer: $ ____________ - cap: $ ____________
- [ ] Public place + daylight agreed (see [Meetup Safety](../08-meetup-safety.md))

## The ask (by text)

- [ ] Exact model + storage (+ cellular or Wi-Fi-only) confirmed in writing
- [ ] Accessory bundle asked about: pen? keyboard? case? charger?
- [ ] "Why are you selling?" answered
- [ ] Battery % stated - ________ %

## At the meetup: hardware, device off (2 min)

- [ ] Corners/edges photographed; screen-off scratch hunt at an angle
- [ ] Frame straight (bent frames can hint at drops or a lying-flat-when-charging past)
- [ ] Charging port clean and firm

## Unlock and identity (2 min)

- [ ] Seller unlocks in my sight
- [ ] About screen: model + storage verified - photo taken
- [ ] Battery Health (iPad: Settings > Battery) read live: ________ %
- [ ] Pen/keyboard pairing details noted (serials if relevant)

## Locks and reset (non-negotiable, from the [locks chapter](../04-locks-and-seed-phrases.md))

- [ ] Sign-out of Apple ID / removal of Google accounts - in my sight
- [ ] Factory reset run in my presence
- [ ] Setup reaches "Hello" with every sign-in skipped cleanly

## Tests (4 min, from [screens](../03-screen-checks.md))

- [ ] Full brightness reached
- [ ] White test: dead dots, blotches, center bright spots - none noted
- [ ] Black + grays: OLED burn-in ghosts - none noted (AMOLED tablets especially)
- [ ] Touch sweep: every edge, all four corners, the diagonal - full coverage
- [ ] Speakers, both sides, stereo confirmed (tablets live on their audio)
- [ ] Camera + front camera with voice recording (video-call duty test)
- [ ] Wi-Fi joins my hotspot and holds several minutes of scrolling
- [ ] Cellular model? Same cellular checks as the [phone worksheet](phone-worksheet.md)
- [ ] Pen (if included): lines, diagonals, **and edge strokes** - pressure sensitivity varies in real strokes
- [ ] Keyboard folio (if included): magnetic snap, every key fires on screen, cursor wanders all corners

## The close

- [ ] Final agreed price: $ ____________
- [ ] Reset verified at "Hello" - before money moves
- [ ] Cash counted; two-line receipt written and signed
- [ ] About photo stored with it

**Red flags found (walk away):** cannot complete a sign-out in person, burn-in that never goes away with grays, pen sold "working, mostly".
