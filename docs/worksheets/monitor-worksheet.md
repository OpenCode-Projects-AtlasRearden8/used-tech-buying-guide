# Monitor Inspection Worksheet

> Monitors are the most over-looked check in used tech: no passwords, no battery, no drama - just pixels. You bring the entire test rig, so nothing is hidden. Ten to twelve minutes.

## Before you leave home

- [ ] Listing screenshot saved (photos of the panel + stand + ports + price)
- [ ] Sold comps written down: 3 prices (same size, resolution, refresh)
- [ ] My walk-in offer: $ ____________ - cap: $ ____________
- [ ] Big-box store lot daylight agreed (see [Meetup Safety](../08-meetup-safety.md))
- [ ] **Packing: your laptop, your cable (HDMI/DisplayPort as needed), USB stick with [the offline color test](../assets/color-test.html)**

## Tests (10-12 min, from the [screens chapter](../03-screen-checks.md))

- [ ] My machine drives it through **each port I will use** (HDMI, DisplayPort, USB-C if advertised); input switching works in the OSD
- [ ] **Pixel-defect scan**: white + red + green + blue fullscreens (color test) - zero dead/stuck dots noted
- [ ] Gray scales: uniformity, any tint shift, any blotchy patch - none noted: ________
- [ ] Black test: backlight bleed read honestly; heavy corner glow noted as the discount it is
- [ ] Brightness slider from max to min: **visible PWM flicker at low brightness** = one of two big monitor red flags
- [ ] Refresh claims (if 120Hz+): OS set to the rated refresh, fast scroll read - the panel shows what it promises
- [ ] Speakers (if present): both sides play, no crackle at moderate volume
- [ ] OSD buttons: every physical button works; menus navigate smoothly
- [ ] Stand: full height travel + tilt (and swivel if advertised); holds positions without sagging
- [ ] VESA holes present (if I plan a mount)
- [ ] **Warm-up window:** ten minutes of conversation on white, then re-look - no newly-appeared lines, tint shifts, or ghosting (driver boards announce themselves here)
- [ ] USB hub (if provided): my stick reads through it

## Quirks that price in (not walk-outs)

- Mild backlight bleed = sellable discount
- A dead pixel in a far corner of an older panel = ~5% reduction
- Missing original stand (third-party stand attached) = $10-25 reduction; be sure it fits
- One dead OSD button = $10-15 reduction - and note the *other* must still navigate

## The close

- [ ] Final agreed price: $ ____________
- [ ] Cash counted before the lift; two-line receipt written and signed
- [ ] Serial number read from the back panel - recorded with the receipt

**Red flags found (walk away):** lines or color pops *appearing* during warmup, panel flicker visible to the naked eye at 60-100%, "the stand broke but the hole still fits" - sale price honesty is not at any number here.

**Walk-away line:** "I'm passing today - good luck with the sale."
